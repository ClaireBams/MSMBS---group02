# Neuroscience

**Course:** KEN3170 — Multi-scale modeling of biological systems  
**Group:** 02

## Objective

Use RSA to compare STG brain responses with untrained and trained auditory models and YAMNet. Analyse the effects of training, architecture and layer depth, and visualise sound categories. This assignment covers Part I only.

## Files

- `assignment.ipynb` — code and analysis.
- `rsa_toolbox.py` — RSA functions from the practical.
- `core.py`, `models.py`, `config.py`, `util.py` — supplied supporting code.
- `instructions_README.md` — original assignment instructions.
- `requirements.txt` — dependencies.

## How to run

1. Download the [data and models](https://filesender.surf.nl/?s=download&token=1518b121-8c37-4e3d-8cf0-2a15717e438c) and extract them into `data/` and `models/` in this folder.
2. Use Python 3.13 and install the dependencies from this folder:```python -m pip install -r requirements.txt```
3. Open `assignment.ipynb`, select the same Python environment, and run the cells in order.
